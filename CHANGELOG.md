# Changelog

As alterações relevantes deste projeto são registradas aqui. O conteúdo segue as categorias de Conventional Commits e será consolidado em cada release SemVer.

## [Unreleased]

### Added

- Navegação SPA com rotas por hash, histórico do navegador e suporte a links diretos.
- Componentes de feedback e validação de formulário no cliente.
- Persistência opcional da preferência de projeto usando `localStorage`.
- Organização JavaScript por funcionalidades e estrutura de diretórios separada.

### Fixed

- Validação de nomes compostos somente por espaços e de formatos de telefone inválidos.
- Overflow horizontal em telas móveis estreitas.
